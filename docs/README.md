## OctoAcme Project Management Principles

The OctoAcme approach is built on these core principles:

- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Deliver small, testable increments
- **Clear ownership**: Each project has a named Project Manager and Product Lead
- **Data-informed decisions**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback and learning

## Project Lifecycle at a Glance

OctoAcme projects follow a structured five-stage lifecycle:

1. **Initiation** → Confirm business need, identify stakeholders, define success criteria, approve to proceed
2. **Planning** → Create prioritized backlog, estimate scope, identify dependencies, define Definition of Done
3. **Execution** → Build, test, review, and iterate with daily standups and regular progress tracking
4. **Release** → Deploy to production, verify functionality, run smoke tests, announce to stakeholders
5. **Close & Retrospective** → Capture learnings, document improvements, and feed insights back into processes

## Key Artifacts

Across the project lifecycle, OctoAcme teams create and maintain:

- **Project Charter / One-pager** — Problem statement, goals, success metrics, stakeholders, timeline, risks
- **Prioritized Backlog** — Itemized work with acceptance criteria, estimates, and ownership
- **Risk Register** — ID, description, impact/probability assessment, mitigation plans, status
- **Release Plan & Milestones** — Key delivery dates and integration points
- **Acceptance Criteria & Definition of Done** — Clear quality standards and completion requirements
- **Retrospective Notes & Action Items** — Learnings, improvements, owners, and due dates

## Communication Cadence

Consistent communication is essential to OctoAcme's success:

- **Daily standups** (15 min) — Team-level progress, blockers, and dependencies
- **Weekly PM + PdM sync** — Alignment on priorities, risks, and decisions
- **Twice-weekly delivery standups** — Detailed execution updates (or as agreed)
- **Monthly stakeholder updates** — High-level progress, milestones achieved, upcoming work
- **Ad-hoc escalations** — For blockers or risks requiring immediate attention
